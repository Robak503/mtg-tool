# 1. WHAT CONTINUOUS EFFECTS ARE (Rule 611)

A continuous effect modifies characteristics of objects or rules of the game for a defined duration. Continuous effects come from two sources:

**From static abilities (611.2):** As long as a static ability's condition is met, its effect is active. These effects begin when the permanent enters the battlefield (or the object with the ability enters the relevant zone) and end when the condition stops being met or the source leaves.

**From resolving spells and abilities (611.3):** Effects generated by spells/abilities that say "until end of turn," "for as long as," or define a specific duration. These are created at resolution and persist until their duration expires.

**Key distinction:** A static ability's effect is always active as long as the ability exists and its condition is met. A spell/ability effect is created at a moment in time and persists independently thereafter.

# 2. THE SEVEN LAYERS (Rule 613)

Characteristics of objects are determined by applying all continuous effects in a specific order — the layer system. Layers are applied in sequence; each layer's output is the input for the next.

## 2.1 The Layer Order

| Layer | What it handles | Rule | Examples |
|---|---|---|---|
| **Layer 1** | Copy effects | 613.1a | Clone, Sakashima, Cytoshape |
| **Layer 2** | Control-changing effects | 613.1b | Threaten, Act of Treason, Bribery |
| **Layer 3** | Text-changing effects | 613.1c | Magical Hack, enchantments that change basic land types |
| **Layer 4** | Type-changing effects | 613.1d | Enchanted Evening, March of the Machines |
| **Layer 5** | Color-changing effects | 613.1e | Painter's Servant, Distorting Lens |
| **Layer 6** | Ability-adding and removing effects | 613.1f | Giant Growth (not P/T part), Silence the Believers |
| **Layer 7** | Power/toughness modification | 613.1g, 613.3–613.4 | Giant Growth (+3/+3), Diminish, base P/T setters |

Layer 7 has internal sublayers — see section 2.2.

## 2.2 Layer 7 Sublayers

Layer 7 is split because P/T modifications interact in order-dependent ways:

| Sublayer | What it handles | Rule |
|---|---|---|
| **7a** | Effects that set P/T to a specific value as part of a copy effect | 613.3a |
| **7b** | Effects that set P/T to a specific value (non-copy) | 613.4b |
| **7c** | Effects that modify P/T without setting (counters, +X/+Y, -X/-Y) | 613.4c |
| **7d** | Switching P/T | 613.4d |

**Why the sublayer order matters:** A +2/+2 effect (7c) applies after a "base P/T 3/3" effect (7b). So a creature with printed 1/1 that gains "base P/T 3/3" and then "+2/+2" is a 5/5 — not a 3/3 that became 1/1+2/+2=3/3. The "base P/T" setter in 7b establishes the value, and the modifier in 7c adds to it.

P/T switches (7d) come last — they swap whatever power and toughness resulted from all previous sublayers.

# 3. APPLYING LAYERS — THE ADJUDICATION PROCESS

When determining an object's characteristics, follow this process:

1. **Start with copiable values** (the printed card, modified by copy effects at layer 1)
2. **Apply control effects** (layer 2)
3. **Apply text-changing effects** (layer 3)
4. **Apply type-changing effects** (layer 4)
5. **Apply color-changing effects** (layer 5)
6. **Apply ability-adding/removing effects** (layer 6)
7. **Apply P/T effects** (layer 7, in sublayer order 7a → 7b → 7c → 7d)

Each layer takes the output of the previous as its input. **Never apply a layer out of order, and never skip back.**

---

# 4. TIMESTAMP ORDER (613.6–613.7)

Within the same layer, if multiple effects would apply, they are applied in **timestamp order** — earliest first. The timestamp of an effect is set when it begins applying.

**Timestamps for static abilities:** Set when the permanent with the ability enters the battlefield (or the zone where the ability functions).

**Timestamps for spell/ability effects:** Set when the resolving effect creates the continuous effect.

**Timestamps for copy effects:** Set when the copy becomes a copy of the object.

**Timestamps for counters (layer 7c):** All counter effects apply simultaneously in layer 7c regardless of when the counters were placed — there is no timestamp order among counters.

## 4.1 The "Last Applied Wins" Heuristic

Within the same layer, applying effects in timestamp order means the most recent effect's output is what stands. This is often described as "last applied wins" — but only within a single layer. Effects in earlier layers always apply before effects in later layers, regardless of timestamps.

---

# 5. DEPENDENCY (613.8)

Dependency is an exception to strict timestamp order. Effect A **depends on** effect B if:
- A is in the same layer (or sublayer) as B, AND
- A's application would change what B does or whether B applies

When A depends on B, B is applied before A in that layer — regardless of timestamps.

**The dependency check:** "If we applied A first and then B, would B behave differently than if we applied B first and then A?" If yes, A depends on B.

**Classic example:** Effect A changes all creatures to artifacts (type-changing, layer 4). Effect B gives "all artifacts" +2/+2. If A is applied first, more creatures become artifacts, which changes what B affects. Therefore A and B may be interdependent, and the dependency rules determine the order.

---

# 6. CHARACTERISTIC-DEFINING ABILITIES (CDAs) (613.1f exception, 604.3)

CDAs are static abilities that define one or more characteristics of the object. They are evaluated continuously rather than being "frozen" at a point in time.

CDAs are applied in layer 6 for most purposes (abilities), but CDAs that define P/T are applied in layer 7b (alongside other effects that set P/T to a specific value).

**Tarmogoyf** has a CDA: "*/1+* where * is..." — this is calculated at layer 7b based on current game state each time it matters.

CDAs that define color, type, or subtype apply in layers 5, 4, or 4 respectively.

---

# 7. TEXT-CHANGING EFFECTS (Rule 612)

Text-changing effects alter the rules text or type line of an object. They apply in layer 3. After text is changed, all subsequent layers read the new text.

**Name stickers (123.6)** are text-changing effects — they modify the name of an object and apply at layer 3.

**"Is" vs. "becomes":** Some text changes use "is" (applying continuously) and some use "becomes" (a one-time change that may be overridden later). In layer 3, both are applied in timestamp order.

---

# 8. SPECIAL CASES

## 8.1 Effects That Generate Other Effects

Some continuous effects modify what other continuous effects do (e.g., "effects that would set power to less than 3 instead set it to 3"). These are handled within the layer system — the modifying effect applies in the same layer as the effect it modifies.

## 8.2 Preventing Effects from Applying (613.5)

Some effects say "this effect can't be countered" or "this effect can't be changed." These are handled at the layer where the effect would apply — the modifying effect simply cannot apply.

## 8.3 Permanents That Lose All Abilities

An effect that causes an object to lose all abilities removes the ability-generating effects at layer 6. The object loses abilities granted by its own text as well as abilities granted by other effects — unless those abilities are from sources that apply at a lower layer (e.g., a layer 1 copy effect defines abilities, but a layer 6 "loses all abilities" removes them).

**Order sensitivity:** If "gains flying" (layer 6, earlier timestamp) and "loses all abilities" (layer 6, later timestamp) both apply, the "loses all abilities" wins — the creature doesn't have flying. If "loses all abilities" has an earlier timestamp and "gains flying" has a later timestamp, the creature does have flying.

---

# 9. CROSS-LAYER CONNECTIONS

**→ Layer 7 (Object Model, 707):** Copy effects (layer 1) use the copiable values framework from rule 707. The layer system determines what characteristics objects actually have after all effects are applied — copiable values are just the starting point.

**→ Layer 5 (SBAs, 704):** SBAs check characteristics after all layers are applied. A creature that is 0/0 due to layer effects is destroyed by SBA even if it was printed as 4/4.

**→ Layer 7 (702 Keywords, 702_t):** Keyword-granting effects enter at layer 6. The taxonomy in 702_t indicates which effects arrive at which layer.

**→ Layer 6 (Casting, 601):** Effects that modify characteristics "as a spell is cast" (611.2f) begin applying as the spell is put on the stack — earlier than most continuous effects.

# COMMANDER ADDENDUM — Continuous Effects in Commander

The layer system (rules 611–613) applies identically in Commander. No Commander-specific rules modify the layer application process.

**Practical Commander notes:**

**Color identity vs. color (layer 5):** Color identity (rule 903.4) is determined before the game begins and is not a continuous effect — it does not run through the layer system. A permanent's in-game color (determined at layer 5) may differ from its color identity. This matters for effects that check "colors" vs. cards that reference "color identity."

**Commander as a permanent:** A commander on the battlefield is subject to all continuous effects normally. If an effect makes it lose all abilities, its commander designation is unaffected (that designation is an attribute of the card, not a characteristic processed by the layers).

**Multiple commanders (Partner):** Each commander is a separate permanent with its own characteristics. Continuous effects apply to each independently through the layer system.

# 9. TRANSFORMATION AND THE LAYER SYSTEM (DFC Interaction)

When a double-faced card (DFC) transforms, the characteristics available to the layer system change — the permanent switches from front-face characteristics to back-face characteristics (or vice versa). This is not a zone change and does not assign a new timestamp to the permanent.

**Key consequences for layer application:**

- Continuous effects that modified characteristics of the front face may no longer apply after transformation if those characteristics no longer exist on the back face (e.g., an effect that granted a creature type the back face doesn't have)
- Continuous effects that apply based on the back face's characteristics become active immediately
- The timestamp of the permanent does not change — its position in layer ordering is unchanged
- Effects that said "this creature has [ability]" that were applied to the permanent before transformation still apply if the back face is also a creature; if the back face is a non-creature, creature-specific effects no longer have a valid application point

**Face-down permanents (morph/manifest):**
- A face-down permanent has no characteristics that layers can meaningfully modify (it's a 2/2 with no name, type, or abilities)
- Turning face-up is also not a zone change — when a permanent turns face up, layers immediately recalculate based on its actual characteristics
- Effects that applied because the permanent was face-down (e.g., "face-down creatures you control get +1/+1") cease; effects that apply based on actual characteristics immediately take effect
