# MTG Tool — static HTML/CSS export (v0.18.0)

Plain HTML/CSS snapshots of the app's screens as they render in **v0.18.0** (the
current `.exe`). The app itself is a Next.js + React app that styles everything
with **inline `style` attributes**, so there are no hand-written HTML/CSS files in
the source — these were produced by rendering the live app and serializing each
screen's DOM. The result is faithful, plain HTML you can open in any browser.

## Files

| File | Screen |
|---|---|
| `index.html` | Main shell — Jace chat, agent sidebar, sessions, right panel |
| `vault-collection.html` | The Vault — Collection tab |
| `vault-build.html` | The Vault — Build (buildable commanders) tab |
| `vault-stats.html` | The Vault — Stats dashboard |
| `vault-sets.html` | The Vault — Set browser (large: lists every set) |
| `vault-finance.html` | The Vault — Finance tab |
| `settings.html` | Settings screen (Models / Display / Privacy / Data / About) — modal open over the shell |
| `deck-view.html` | Deck view — list, Deck Report, Recommendations, Version History |
| `academy.html` | The Academy (learn-to-play) setup screen |
| `styles.css` | The app's global resets (`globals.css`). Every screen links it. |

## How to view

Open any `.html` in a browser. They link `styles.css` (keep it alongside them).

## What these are / aren't

- **Faithful** to v0.18.0 — real markup + the exact inline styles the app renders.
- **Static / non-interactive** — no JavaScript, no data, no server. Buttons,
  tabs, and inputs won't do anything; they show the rendered look only.
- **Card art is blank** — the app loads art from a local `/api/art-crop` proxy
  that only exists when the app is running, so `<img>`/background art won't
  resolve here.
- The `@font-face` block in each file points at the dev server's font files and
  won't load standalone; the app's actual type is the system serif (Georgia),
  which renders fine without it.

Generated by serializing the running app's DOM (scripts stripped, stylesheet
link repointed to `styles.css`).
